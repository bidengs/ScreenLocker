# Screen Locker

一个简洁高效的安卓屏幕锁定应用，提供一键锁屏功能，支持多语言和自定义主题。

## 功能特性

### 核心功能
- **一键锁屏** - 点击悬浮电源按钮即可快速锁屏
- **悬浮按钮** - 可拖动的电源符号按钮，始终悬浮在屏幕上方
- **实时状态** - 主界面实时显示权限状态和悬浮窗运行状态

### 权限管理
- **悬浮窗权限** - 自动检测权限状态，一键跳转系统权限页面
- **设备管理员** - 自动检测设备管理员状态，一键激活

### 个性化
- **多语言支持** - 支持中文、英文、日文
- **主题色自定义** - 9种主题色可选，悬浮按钮和界面主题色同步更新

### 用户体验
- **响应式设计** - 基于Material Design 3，适配各种屏幕尺寸
- **智能状态同步** - 权限变更和状态变化自动同步到界面
- **流畅动画** - 按钮点击和状态切换都有流畅的过渡动画

###注意事项
本应用为安卓8及以下设备设计，使用设备管理员权限实现锁屏，唤醒屏幕会强制使用密码解锁

## 技术栈

- **语言**: Kotlin
- **UI框架**: Jetpack Compose
- **设计系统**: Material Design 3
- **架构**: 单Activity + Compose UI
- **服务**: Android Foreground Service
- **权限管理**: DevicePolicyManager API

## 系统要求

- Android 7.0 (API 24) 或更高版本
- 推荐使用 Android 8.0 (API 26) 及以上版本

## 安装与使用

### 安装
下载APK文件安装，打开应用后按照提示授予必要权限。

### 使用
1. 授予悬浮窗权限
2. 激活设备管理员
3. 打开悬浮按钮开关
4. 点击悬浮按钮即可锁屏
